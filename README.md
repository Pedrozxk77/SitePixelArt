# Celeste Fan Page

## Descrição
Site estático sobre o jogo Celeste, desenvolvido com HTML e CSS para apresentar o tema de games em pixel art, com navegação, imagens, textos informativos e uma identidade visual inspirada no jogo.

## Tecnologias
- HTML5
- CSS3
- Git
- GitHub
- Vercel

## Como executar localmente
1. Abra a pasta do projeto.
2. Abra o arquivo index.html em um navegador ou utilize uma extensão como Live Server no VS Code.
3. Para visualizar o projeto completo, acesse as páginas sobre.html e contato.html pelo menu de navegação.
